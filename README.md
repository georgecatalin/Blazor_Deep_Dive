# Blazor Deep Dive: From Beginner to Advanced

Personal hands-on practice repository accompanying the Udemy course [Blazor Deep Dive: From Beginner to Advanced](https://www.udemy.com/course/blazor-deep-dive-from-beginner-to-advanced/) taught by Frank Liu.

This repository contains step-by-step implementations, exercises, architectural experiments, and practical course projects spanning modern Blazor full-stack development.


## 🎯 Repository Objectives

- Master modern Blazor render modes and hosting patterns (.NET 8+ / .NET 9).
- Implement component architecture with clean separation of concerns.
- Practice data access strategies using Entity Framework Core and Web API endpoints.
- Build, style, test, and secure interactive Blazor client and server components.


## 🛠 Tech Stack & Tools

- **Language:** C#
- **Framework:** ASP.NET Core Blazor (.NET 8 / .NET 9)
- **Data Persistence:** Entity Framework Core, SQL Server / SQLite, RESTful Web API
- **Tooling:** Visual Studio / Visual Studio Code, .NET CLI
- **Front-End / UI:** Razor Syntax, CSS Isolation, QuickGrid
